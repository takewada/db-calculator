dB Calculator

Five linked tools for power, voltage, unit and mismatch calculations — dBm level summing, correlated/uncorrelated voltage summing, a full unit converter, a dB↔ratio converter, and a VSWR/return-loss converter.

Uncorrelated sums power‑wise: V = √(ΣVᵢ²) (e.g. independent noise sources). Correlated sums voltage‑wise: V = ΣVᵢ (e.g. coherent signals in phase). The two give very different results for the same input levels.

Unit Converter

Enter one value in any unit and the impedance it's referenced to; every other power and voltage unit is computed at once.

dBu is referenced to 0.775 V regardless of impedance; every other power↔voltage conversion uses the impedance above.

dB Converter

Converts a linear ratio to dB, or a dB value back to a linear ratio — edit either field, the other updates.

Power: dB = 10·log₁₀(ratio)  ·  ratio = 10^(dB/10)

VSWR Converter

Converts between reflection quantities — VSWR, reflection coefficient Γ, return loss and mismatch loss — and, given a forward power or voltage, the reflected value.

Γ = (VSWR−1)/(VSWR+1) · Return loss = −20·log₁₀Γ dB · Mismatch loss = −10·log₁₀(1−Γ²) dB · reflected power = Γ²·forward power.

All five tools compute locally in this page — no data leaves your browser.
